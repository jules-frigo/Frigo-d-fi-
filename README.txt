FRIGODÉFI — installation sur iPhone

IMPORTANT : ce dossier contient l'application, mais pour l'installer comme une PWA sur iPhone, il faut d'abord publier ces fichiers sur un hébergement HTTPS (par exemple GitHub Pages). Le ZIP seul ne crée pas un lien public.

Méthode d'utilisation locale :
- Décompressez le ZIP sur un ordinateur.
- Ouvrez index.html dans un navigateur pour tester le quiz.

Pour l'ajouter à l'écran d'accueil de l'iPhone après publication :
1. Ouvrez l'adresse HTTPS dans Safari.
2. Touchez le bouton Partager.
3. Choisissez « Sur l'écran d'accueil ».
4. Touchez « Ajouter ».

Le score est conservé pendant la session ouverte, mais cette version ne synchronise pas les résultats entre appareils.
